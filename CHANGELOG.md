# Changelog

## 0.1.0 — 2026-11-06

- Initial public release.
- Account-wide token totals and actual CNY spend from DeepSeek Platform's
  usage API, with 7-day / 30-day / all-time ranges and DSH-only / all-key
  scopes.
- Local session ledger with historical backfill, four token buckets, estimated
  peak/off-peak cost, daily chart, model mix, and recent sessions.
- Left-sidebar entry, compact footer total, and a stable 960px panel layout.
- Separate aligned chart axes for 14-day, 30-day, and all-time views.
